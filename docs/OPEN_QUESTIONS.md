## Uncertainty reminders

A detected rotating compact object does not imply the large-scale universe rotates. An angular-momentum operator exists even when the state has zero angular momentum. A scalar with an internal winding defect does not imply a rotating metric. A galaxy handedness statistic does not by itself establish an invariant vorticity tensor. A mathematically consistent rotating cosmology need not describe the observed universe.

**The proposal is worth investigating precisely because it can fail.**
