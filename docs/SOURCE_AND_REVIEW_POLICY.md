# Source, review and evidence policy

This repository is an independent synthesis, not an institutional collaboration or a proof announcement.

- **Canonical preservation:** Monolithic_102_EFMW equations are quoted/referenced exactly by number and link. The research atlas does not silently edit canonical sources or import third-party code.
- **Source attributions:** Matthew Chenoweth Wright/Monolithic LLC authors/curates the new research descriptions; external work (Planck Collaboration, BSA-R/Duguay, BEC laboratories, GR measurements, etc.) retains the original authorship. References are evidence, not endorsements or licensing grants.
- **Source types:** `peer_reviewed_observation`, `observatory_release`, `peer_reviewed_controversial`, `formal_source`, `source_model`, `research_notes`, `theoretical_model`. Source type is not the same as evidence status.
- **Dates:** Selected works span 1975–2026; not exhaustive. Search/retrieval in November 2026 is not evidence that these are the newest possible constraints.
- **Primary claims:** A measured frame-dragging signal supports a local GR effect. A paper discussing rotating universes is not empirical evidence of one.
- **Reproducibility:** A committed script with tests is not independent confirmation. Existing Lean source proofs need fresh pinned kernel builds; observational numbers need original likelihood/data access.
- **Uncertainty:** Each register claim includes at least one limitation. Missing essential proof = `OPEN`, not `PASS`.
- **Correction:** Any reader may submit a counterexample, documented correction, measured null, relevant independent study, or source provenance fix. Accepted revisions must preserve prior audit history and identify the exact changed claim.
- **Privacy:** Do not import private communications, personal datasets or restricted images without explicit permission.
- **No claim inflation:** No paper, README or presentation should say this atlas demonstrates the observable universe globally rotates. That hypothesis has not been established.
